# Concepts

lawkeep has a handful of ideas. Each page below explains one in plain words first, then the
details.

| Idea | In one sentence |
| --- | --- |
| [Laws](laws.md) | a rule your code must always follow: one plain sentence plus a check lawkeep runs |
| [Drafts and approval](drafts-and-approval.md) | agents write laws; a person says yes or no after seeing real examples |
| [Permissions by direction](directions.md) | every law change is stricter, the same, looser or unclear, and your settings say which ones need your yes |
| [Law history and lock](history-and-lock.md) | every law change is recorded, and any change made outside lawkeep is noticed |
| [The gate and result codes](gate.md) | `lawkeep check` runs every law and answers `ALL LAWS HOLD` or `SOME LAWS FAIL` |
| [Law strength](strength.md) | lawkeep plants bugs to tell you when a law is too weak to catch them |
| [Protection report](protection.md) | which changed functions your laws protect, and which you still need to read |
| [Waiting list and person present](waiting-list.md) | everything that waits for a person in one place, and how agents know whether you are there |
