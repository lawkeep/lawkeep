# Security policy

## Supported versions

lawkeep is in early development (0.x). Only the latest release on
[PyPI](https://pypi.org/project/lawkeep/) gets fixes.

## Reporting a vulnerability

Please do **not** open a public issue. Report it privately through GitHub:
**Security → Report a vulnerability** on [github.com/lawkeep/lawkeep](https://github.com/lawkeep/lawkeep/security/advisories/new).
Include what you found, how to reproduce it, and the lawkeep version.

Ways an AI agent can get around lawkeep without it being reported (a silent bypass of the law
history, the gate or the guard) count as security issues. Known limits are listed in the README
under "Known limits".
